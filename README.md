# Ridge - Statamic Starter Kit

Ridge is a construction starter kit for residential builders, commercial contractors, and project-led firms. It is built for Statamic 5 with a rust-and-sand palette, named project leads, a job schedule, and Control Panel content management.

The kit ships four home variants, project listings, booking, events, shop pages, blog and podcast layouts, and membership content so a contractor can publish jobs and take project inquiries from one site.

## Collections

Organize your content with built-in collections (handles in parentheses):

- **Pages**: Site structure and hierarchical content.
- **Projects** (`classes`): Homes, commercial jobs, and case work.
- **Events**: Openings, site tours, and trade days.
- **Services** (`retreats`): Build packages and trade offerings.
- **Products**: Materials and shop items.
- **Blogs**: Jobsite stories and company news.
- **Podcast** and **Podcast episode**: Audio series and individual episodes.
- **Teams**: Project leads and crew.
- **Testimonials**: Client reviews.
- **FAQs**: Bidding and build questions.
- **Comments**: Blog and project comments.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Ridge.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/ridge-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Ridge in one command:

```bash
statamic new my-site webbycrown/ridge-statamic-theme
```
