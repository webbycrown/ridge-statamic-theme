# Ridge - Statamic Starter Kit

Ridge is a construction starter kit for homes and commercial jobs with named leads and a schedule you can book. Built for Statamic CMS with a modern layout and Control Panel content management.

## Pages of Ridge

- Home Pages: 4 variants
- About Us
- Projects listing, detail, category, and booking
- Schedule
- Events listing and detail
- Services listing and detail
- Blog listing and detail
- Podcast listing and episode detail
- Team listing and member detail
- FAQ, testimonials, membership, privacy, terms, contact, 404

## Collections

Pages, blogs, projects, events, services, podcasts, teams, testimonials, FAQs, comments.

## Features

- Rich page builder with flexible sets
- Theme-ready design with Tailwind CSS
- Global settings for header, footer, and site-wide copy
- Responsive layout
- Statamic 5 ready

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit). Use **Statamic 5.x**.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/ridge-statamic-theme
```

### Installing via the Statamic CLI Tool

```bash
statamic new my-site webbycrown/ridge-statamic-theme
```
